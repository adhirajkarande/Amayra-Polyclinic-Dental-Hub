# Amayra Polyclinic & Dental Hub — Website Source

Static HTML/CSS dental website for amayradentalpune.com.

## Upload
Upload the **contents of `amayra-site/`** into Hostinger `public_html/` so that `index.html` sits directly inside `public_html`.

## Main files
- `index.html` — homepage
- `styles.css` — global design system
- `location-page.css` — landing-page styles
- `assets/` — logo, clinic visuals, doctor portrait and treatment images
- `sitemap.xml` — XML sitemap
- `robots.txt` — crawler rules

## Notes
- The Dr. Rupali Karande portrait in `assets/dr-rupali-karande.jpg` is the clinic-provided image supplied for this build.
- Clinic/interior and treatment visuals are illustrative website imagery and should not be represented as photographs of the actual clinic unless replaced with real clinic photographs.
- Replace illustrative visuals with approved Amayra photographs when available.
